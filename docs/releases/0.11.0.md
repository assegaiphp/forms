# Assegai Forms 0.11.0

Forms joins the coordinated AssegaiPHP 0.11 framework line without changing its
form APIs. Collections, Util and Validation requirements retain their existing
`^0.10.0` support while also accepting `~0.11.0`. The recommended coordinated
installation uses the 0.11 package set; module release alignment does not remove
verified compatibility with the earlier dependencies.

Upgrade the installed framework modules together and run the application's form
and validation tests after Composer resolves the published 0.11 package set.
No source-level form migration is required by this synchronization.
